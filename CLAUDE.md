# Atlas — правила для Claude

Atlas — новая платформа Грегори (создана 2026-10-27): карта-глобус для путешествий + просмотр и правка фото. Собирается заново, по одной функции, из двух проектов, которые остаются рабочими резервными копиями и **не перестраиваются**:

- **travel-earth** (`C:\Users\Grigori\.GitHUB\travel-earth`, GitHub Pages) — карта, слои, экскурсии с аудиогидом, разговорники, фото Commons/Mapillary/свои, галерея с видео и живыми фото. Подробности и все решения Грегори — в его `CLAUDE.md`.
- **photo-editor / Albom** (`E:\.GitHub\photo-editor\repo`) — правка фото: горизонт (OpenCV.js), поворот, перспектива, кадрирование, цвет, шумоподавление, EXIF.

Грегори (2026-10-27): «Не будем гнездить старые проекты — это разрушит их, и на какой-то момент не будет ничего». Старые проекты заморожены: только исправления ошибок. Новое — только в Atlas.

Цель — «площадка, максимально адаптивная для будущих концептов работы с графикой: появилось что-то новенькое — прикрутили». Грегори общается по-русски, тексты интерфейса — для людей, без технических подробностей.

## Устройство: ядро + модули

```
core/      карта, общий стиль, реестр модулей (modules.js), события (events.js),
           настройки (settings.js), окно-панель (panel.js), панель «Слои» (layers-panel.js)
layers/    слои карты
content/   разделы с панелью: Языки (дальше — Экскурсии, Мои альбомы)
sources/   источники фото
tools/     инструменты окна просмотра (правка фото)
voices/    голоса для чтения
```

- Модуль — файл в своей папке, вызывает `register({...})` из `core/modules.js`; подключается строкой в `MODULES`. Ядро модули по именам не знает.
- **Тяжёлое — только по надобности:** библиотеки и модели модуль грузит в `load()`, при первом включении, а не при старте.
- Модуль сам объявляет, что ему нужно (`needs`: folders, webgpu, network, desktop). **Правило недоступного:** нет возможности на этом устройстве — модуль не показывается; есть возможность, но нет данных — кнопка видна и неактивна (`disabled`). Это примиряет правило photo-editor «ничего не прятать» и решение travel-earth «на телефоне разделы папок не нужны».
- **Связь модулей — только события** (`core/events.js`: `on`/`emit`, последнее значение запоминается); имена событий перечислены в начале файла, новое — дописать туда.
- **Окно — только `createPanel`** (`core/panel.js`): одновременно открыта одна панель, шапка «название · свернуть · закрыть», свёрнутость помнится. Свои окна модули не рисуют.
- **Кнопки слоёв — колесо-барабан в боковой панели справа** (`core/layers-panel.js`, Грегори 2026-10-29, сменило меню как у Windy): панель открывается и прячется треугольником **в правом нижнем углу, поверх ленты фото** (`.wheel-toggle`: размером с другие кнопки, прозрачный фон, без каймы; ◀ — показать, ▶ — спрятать; открытость помнится, `layers.panel`), на телефоне панель смахивается вправо. Барабан как в игровом автомате или выборе даты: **размер кнопок один, меняются промежутки** — в центре самые большие, к краям меньше (`y = R·sin(d·θ)`, видно до 7), кнопки у краёв темнеют; крутится колёсиком и пальцем **по кругу**, у центра притормаживает (`shown()`: `v − 0,7·sin(2πv)/2π`), после прокрутки встаёт кнопкой в центр. **Нажатие по центральной — открыть её столбик, по другой — докрутить в центр и сразу открыть**; столбик слева от барабана, **по центру относительно кнопки**, кнопки прижаты вправо, значок справа; глубина — один щелчок. Барабан: **верх — вровень со строкой поиска, низ — постоянно 76 px от низа окна** при любом размере (Грегори: «нижний ограничь и не трогай даже при сильном сжатии»); на телефоне — от-под поиска до ленты фото. **Цвет по группам** (`tone` в `GROUPS`, переменные `--tone-*`): карты, линии (тропы, дороги), точки (места, транспорт, магазины), фото, погода; **выключено — яркая заливка цвета группы, включено — светлая** (Грегори: «наоборот» — иначе не разобрать группы) и крестик в углу (снимает всё в кнопке и закрывает её столбик); выделенные кнопки столбика — светлой заливкой цвета группы, остальные выделения в панелях — светлым `--active`. **«Карты»** — первая кнопка, в кружке миниатюра текущей карты; в столбике пять карт с миниатюрами (выбранная — в кольце) и под чертой рельеф (раздел `relief`: «Тени и 3D», «Высоты»). Плитки карт внизу больше нет (`core/basemaps.js` — только `setBasemap`). Модуль с видами (`menu`) — своя кнопка (Транспорт, Магазины, Тропы, Велодорожки, Дороги); если название совпадает с разделом — остальные слои раздела в ней под видами (Дороги + Железные дороги). Виды — `core/profiles.js` (`profileMenu`): отмечать можно несколько, пункта «Все…» нет. Где цвет на карте что-то значит — значок кнопки столбика в кольце этого цвета (`color`). Открылась панель настроек — колесо прячется, и наоборот (`closeOpen()`).
- `layers/photos.js` — кружок «Фото» (Грегори, 2026-10-28): «Фото» — снимки Wikimedia Commons, **алгоритм travel-earth** (Грегори, 2026-10-29: «высыпает фотки сразу все… должны быть просто точки и потом миниатюры»): со шкалы «20 км» — только точки (редкая проба: узел сетки на ~180 px — реже прежних 100, это были десятки поисковых запросов ради сотни точек, круг 10 км, по точке на четверть круга), со «3 км» — квадраты тайлов z12+ целиком, **все снимки точками сразу**, потом **миниатюры**, четвертинки переполненных квадратов (500 точек) — последними. **Две очереди, в каждой один запрос за раз** (просьба Wikimedia): поиск (точки) и сведения о снимках (миниатюры) — «поиск занят» касается только поиска, поэтому миниатюры не ждут четвертинок, а начинаются, как только загружены точки основного уровня в кадре. Загрузка начинается по `moveend`, не по `idle` (не ждёт, пока дорисуется подложка). **Найденное помнится на устройстве неделю** (`cacheGet`/`cacheSet`: `commons/cell|probe/<z/x/y>`, `commons/info/<pageid>`) — знакомые места без запросов. Размеры миниатюр — только стандартные Wikimedia (120, 330, 1920; с 2026 нестандартные CDN отклоняет) (Грегори, 2026-10-29: «без миниатюр точки загружаются мгновенно… высыпать все точки, и только потом подгружать миниатюры»): по одной на клетку экрана 64 px (ближайшая к середине; клетка с миниатюрой готова, приблизили — клеток на местности больше), `imageinfo` пачкой до 50 — автор/лицензия/дата; снимок без миниатюры помечается `failed`; с «1 км» — миниатюры 44 px в белой рамке поверх точек (свой источник `photo-commons-thumbs`). **Налезающие точки — один кружок с числом снимков** (Грегори, 2026-10-29: «правило, ограничивающее количество точек на квадрат, нарушать нельзя… на перекрывающихся точках писать просто цифру»): источник `photo-commons` собирает точки ближе 18 px (`cluster`), число — слой `photo-commons-count`, щелчок по кружку — приближение, пока не распадётся. Commons часто отвечает «поиск занят» (`cirrussearch-too-busy`, код 200) и «too many requests» при параллельных запросах — запросы строго по одному, после отказа пауза 1,5 с, вдвое дольше до 15 с. «Снимки улиц» — Mapillary (ключ — открытый Client Token Грегори из travel-earth): линии съёмки с «1 км» (тайлы только z13), точки снимков со «100 м» (только z14) — тяжёлые тайлы, по источнику на уровень, при выключении источники удаляются; щелчок — снимок (Graph API), щелчок по снимку / «Смотреть в плеере» / двойной щелчок по линии — **плеер `viewer.html`** (MapillaryJS 4.1.2, тёмное отдельное окно `atlas-streets`, можно унести на другой монитор), он шлёт `postMessage` с положением и направлением камеры — на карте розовая точка с веером, карта подвигается. «Веб-камеры» — OSM `webcam`/`contact:webcam` (~10 тыс., один запрос QLever на весь мир; точки — со шкалы «100 км» (Грегори 2026-10-29: на глобусе значки сыпались кучей, потом «ограничить видимость 100 км»), значки — со «3 км»), в окне — ссылка, а если она на картинку — кадр. `stats()` — для проверки.
- `core/photo-strip.js` — **лента снимков внизу и галерея** (Грегори, 2026-10-29: «ленту с превью найденных фоток внизу экрана и переходом в альбом в отдельном окне при даблклике; и может у веб-камер тоже»), как в travel-earth: со шкалы «3 км», снимки в кадре слева направо, ушедшие убираются, колесо крутит вбок; внизу от края до края, **поверх** кнопок слева внизу — кнопки не сдвигаются (Грегори, 2026-10-29: «когда кнопки прыгают — очень некрасиво, всегда можно этого избежать»); над лентой поднимается только строка состояния (`body.has-photo-strip`). Источник отдаёт `setStripItems(source, items)` (`{ id, coordinates, thumb, title, full, credit, link, select }`), ядро источники по именам не знает. Щелчок — выделение (розовое кольцо `photo-strip-selected` на карте, рамка в ленте) и окно снимка; двойной щелчок (и по миниатюре на карте) — `gallery.html`, тёмное отдельное окно `atlas-gallery` (список берёт у карты через `window.opener.atlasGallery()`): ← → Home End, свайп, Esc; листание выделяет снимок на карте и подвигает её. В ленте — Commons с миниатюрой и веб-камеры, у которых ссылка ведёт прямо на картинку (в Таллине так почти все — перекрёстки `ristmikud.tallinn.ee`); у остальных камер — страница сайта, превью нет.
- **Разделы с панелью** (`kind: "content"`, папка `content/`; Грегори, 2026-10-29: «берём из Travel Earth Языки, Экскурсии и Мои альбомы», по одному, каждый выкладывается отдельно): своя кнопка в барабане (цвет — `tone` модуля), её столбик — список (поле `column`: `load()` при первом открытии, `items()`, `choose(id)`, `isOpen()`, `close()`), нажатие открывает **панель слева под поиском** (`createPanel({ side: "left" })`, колесо при ней на компьютере не прячется; на телефоне прячется), кнопка раздела светлая, пока панель открыта, её крестик закрывает панель. **В строке поиска — значок режима** (Грегори: «без окна поиска не обойтись; после выбора режима должен появляться значок»): `setSearchMode({ icon, title, placeholder, filter, exit })` из `core/search.js`, ввод ищет внутри раздела на каждую букву, значок с крестиком при наведении — обратно к поиску мест (и закрыть панель). Данные — `core/repo.js` (папки репозитория travel-earth: дерево — GitHub API, помнится час, запасной список — jsDelivr; файлы — с сайта travel-earth с `?v=хэш`, прочитанные помнятся по хэшу), голос — `core/speech.js` (лучший голос языка, чтение по предложениям, «разблокировка» на Android), флаги — `core/flags.js` (flagcdn).
- `content/languages.js` — **Языки**: разговорники папки «Языки» (до трёх файлов на язык — вкладки «Разговорник / Словарь / Общие фразы», язык группируется по коду `Язык:`), столбик — языки с флагами, панель — «О языке», разделы (открыты первый и первый с фразами), фраза — щелчок читает её голосом языка, плеер «все подряд» (раздел, по-русски, на языке; щелчок по фразе во время чтения — продолжить с неё), «свернуть все»; режим поиска «Найти фразу». Формат файла — как в travel-earth (промт `Языки/_Промт — как написать разговорник.md`).
- **Подсказок «Приблизьте карту» и «не найдено» нет** (Грегори, 2026-10-29: «никто не читает, а область свайпа ограничивают») — строка состояния только для ошибок (не загрузилось, нет доступа к местоположению).
- **Сеть:** модуль с полем `sends` подчиняется режиму «без сети» и запрету в настройках (`allowed()` в `modules.js`); запрещённый — кнопка видна и неактивна. Свои запросы в сеть модуль делает только в `enable`/`load`, не при старте.
- **Большие файлы (модели, голоса) — только через `model()` из `core/storage.js`:** скачиваются один раз, видны и удаляются в настройках. Мелкие кэши — `cacheGet`/`cacheSet`.
- **Настройки — только `core/settings.js`** (ключи `atlas.*`), чтобы выгрузка в файл забирала всё.
- Без сборщика: обычные ES-модули, библиотеки с unpkg с точной версией.

## Карта (core)

- `core/basemaps.js` — подложки (5 карт; «Светлую» Грегори убрал 2026-10-25), выбор — в колесе, кнопка «Карты». Смена — `setStyle(…, { diff: false })` и событие `basemap` (`dark` — для светлых подписей своих значков). После смены стиля всё своё ставится заново по `style.load`.
- `core/labels.js` — язык подписей (`coalesce(name:xx, name)`), кнопка — внутри строки поиска; `uiLanguage()` — язык ответов поиска и описаний.
- `core/search.js` — поиск Nominatim (только по Enter/лупе — правила Nominatim), история-избранное. Это модуль-служба (`kind: "service"`, `sends`) — подчиняется режиму «без сети».
- Наклон карты — до 65° (`maxPitch` в app.js; стандарт MapLibre 60°, Грегори 2026-10-28: «ещё на 5 градусов»).
- Строка источников свёрнута в ⓘ (удалять нельзя — лицензии).
- `core/controls.js` — шкала (подписи MapLibre по-русски через `locale` в app.js), «Где я» (слежение помнится), звёздное небо (холст под прозрачной картой; без мерцания при «меньше движения» в системе). **Столбик слева внизу** снизу вверх: настройки, «+ −», компас, «Где я»; справа от шестерёнки, **в одну линию с ней**, — ⓘ в совсем тонком ободке и шкала (Грегори, 2026-10-29: справа остаётся только треугольник панели). Строка поиска — 480 px, высотой 40 px (Грегори: 48 «слишком высокое»), на телефоне во всю ширину, белая (тёмную «как у Google» Грегори вернул обратно), **слева — логотип Atlas** (`icons/logo.png` из `tools/make-icons.py`: глобус светлее, кант вокруг него тонкий, вокруг метки — чёткий); **первая строка настроек — «Поделиться»** — ссылка на сайт программы (`SITE`; Грегори: «а не на геолокацию»), системное окно «Поделиться», иначе ссылка копируется; панель настроек — справа вверху (на телефоне — под поиском).
- `core/place-info.js` — окно места по щелчку: значок/подпись карты → название, вид, Википедия, часы, сайт; пустое место → координаты (копируются) и адрес; мимо глобуса — ничего. Служба с `sends`.
- `layers/places.js` — категории мест: шесть модулей `places/*` с `group: "places"` (в панели — раздел «Места»; можно несколько сразу — Грегори 2026-10-28; у каждой категории свой слой `places-poi-<id>`), тайлы OpenFreeMap `poi`, флажки с белым кантом (не тенью), транспорт — цвет по виду, аэропорты со «5 км», остановки со «100 м»; у магазинов — `menu` с профилями, у каждого вида свой значок товара (`SHOP_ICONS`; Грегори, 2026-10-29: «на кнопке продукты — банан, в панели разные продукты»: банан, лоток с навесом, ключ, футболка, телефон, аптека, пакет, подарок, бокал), у кружка «Магазины» — тележка. Свои слои — `claimLayers()`, окно по флажку — `featureContent()` из place-info.
- `layers/trails.js` — тропы (Waymarked Trails): картинки со «20 км» до зума 11, свои линии с номерами с 11, **с 14 — полная геометрия** маршрутов в кадре из `details/relation` (сервер упрощает `list/segments` сам — `ST_SimplifyVW(1000)`, точка ~100 м, параметра нет; Грегори 2026-10-27: «можно ли сделать больше точек?»). Полная геометрия кэшируется (`cacheSet`), упрощённые отрезки такого маршрута прячутся. `by_area` отдаёт не больше 100 маршрутов — такой квадрат делится на четыре (до 1/8). Проверка — `stats()` модуля. В панели — свой раздел «Тропы» (`group: "trails"`): «Тропы» и «Велодорожки» с меню «Все велодорожки / Веломаршруты / Маунтинбайк» (Грегори, 2026-10-28; вид помнится, `trails.cycling.profile`); у «Троп» меню по значимости «Все / Международные / Национальные / Региональные / Местные» (цвет линии = значимость; фильтр по `rank` только своим линиям с зума 11 — картинки издалека показывают все тропы, Грегори 2026-10-28; `trails.hiking.profile`). `makeKind()` даёт управляемый слой (`setRanks`), модули собираются из них. Значки (Грегори, 2026-10-29): у «Троп» — пешеход с рюкзаком и палкой, по картинке Грегори (босые стопы в любом виде «похожи на кальмара» — не возвращать), у видов — обувь сбоку от тяжёлой к лёгкой (`SHOES`: международные — высокий ботинок, национальные — пониже, региональные — кроссовок, местные — носок; кроссовок и носок — по картинкам Грегори); у «Маунтинбайка» — велосипед в гору на наклонной полоске дороги.
- `layers/terrain.js` — «Рельеф» одной кнопкой: тени склонов + 3D (Грегори, 2026-10-28: «объединить Рельеф с 3D-рельефом»), «Высоты» — горизонтали с подписями (кнопка переименована Грегори 2026-10-28; maplibre-contour грузится по надобности), железные дороги. `layers/outdoor.js` — пляжи, сёрфинг (+ `surf-spots.json` — кайт-споты Грегори), значки у троп (`group: "hidden"`, включаются сами вместе с любыми тропами). Запросы к QLever — `core/qlever.js`.
- `layers/roads.js` — «Дороги» (Грегори, 2026-10-28): тайлы OpenFreeMap `transportation`, цвет и толщина по классу, грунтовые (`surface=unpaved`, `track`) — пунктиром, тоннели — полупрозрачным пунктиром; виды Автомагистрали / Главные / Местные / Грунтовые — значки дорожными знаками (Грегори, 2026-10-29: «значки машин заменим на дорожные знаки»: автомагистраль — две проезжие части вдаль, без моста (с мостом «похож на домик»); главная дорога; пересечение со второстепенной; неровная дорога; у «Железных дорог» — крупный паровоз без треугольника), у кружка — машина (`roads.profile`), повторное включение меняет фильтр.
- `layers/weather.js` — «Ветер» (Open-Meteo: сетка в кадре кратна шагу, ответы на час; сила в м/с — Грегори 2026-10-28: «измени показания ветра на m/s»; цвет по силе как у Windy, пороги пересчитаны в м/с) и «Осадки» (RainViewer: 8 кадров за 2 часа анимацией; бесплатно только до зума 7). В панели — раздел «Погода».
- **Перенос правок travel-earth 2026-10-28:** слой пеших маршрутов называется **«Тропы»** (Грегори: «замени везде пешие прогулки на тропы»). Значки у троп: щиты/указатели/карты/инфостенды с тегом `image` — оранжевое кольцо вокруг обычного значка (`outdoor-<kind>-photo`, признак `hasPhoto` из того же запроса QLever), фото — в окне по щелчку (`photoUrl`: ссылка или `File:` → Commons `Special:FilePath`); капли воды — отдельный слой `trail-poi-water`, со шкалы «30 м» и крупнее. Транспорт: значок в булавке 30 px вместо 22; вокзалы и станции фуникулёров видны со «3 км» — слой `places-transport-far` из QLever (квадраты 1°) до зума 12, дальше тайлы; станции фуникулёров (station=funicular / funicular=yes) — зелёная булавка с наклонённым вагончиком, в тайлах узнаются по id (`funicularIds`). Канатные дороги (Грегори: «в Atlas нет канатных дорог, в Travel Earth в Барселоне были с линиями»): тросы и рельсы фуникулёров — зелёный слой `places-lift-line`; станции канаток — по id троса из OSM API (`way/…/full`, узлы aerialway=station) в слое `places-cable` до зума 14, дальше — из тайлов; в окне — «Станция канатной дороги» (`kindOf` смотрит class aerialway раньше subclass). **Издалека, как фуникулёры** (Грегори, 2026-10-28: «подними по видимости канатные дороги до фуникулёров»): со шкалы «3 км» до зума 12 тросы (`places-cable-far-line`, WKT из QLever → `wktLines`) и станции канаток (subclass `cable` в `places-transport-far`) приходят из QLever квадратом 1° (`cableLoader`); у вида поле `far` включает "cable".
- **Транспорт — меню видов, как у «Магазинов»** (Грегори, 2026-10-28: «каждый транспорт отдельно выпадающим списком»): `TRANSPORT_PROFILES` в `layers/places.js` — Весь транспорт, Поезда и вокзалы, Метро, Трамваи, Автобусы, Паромы, Фуникулёры и канатные дороги, Аэропорты; у вида поля `subclasses`/`stops`/`airports`/`far` (дальние станции из QLever)/`cable` (тросы и станции канаток)/`lifts`/`rail`; выбранный вид помнится (`places.transport.profile`).
- **Окна на карте — только через `track()` из `core/popups.js`:** все закрываются при движении карты, первый щелчок при открытом окне только закрывает. `map.transform` в MapLibre 6 нет — «точка на Земле?» проверяется через `project(unproject(p))`.

## Стиль — один на всё

- Все цвета, шрифт, размеры, скругления — переменные в `core/style.css`. Модуль своих цветов не заводит.
- Общие элементы — один CSS-класс (`.btn` и т. п.), без точечных переопределений по месту.
- Значки — монохромные (`currentColor`), с тонким кантом вместо тени; светлым значкам — кант контрастного цвета.
- Нажатая/выделенная кнопка — светлая заливка (`--active`, тёмный текст), не белый и не прозрачный фон.
- Карта и панели над ней — светлые; окно просмотра и правки фото — тёмное.

## Данные

Экскурсии, Языки и Альбомы пока живут в репозитории **travel-earth** — Atlas читает их оттуда (GitHub API / raw), ChatGPT продолжает писать туда же (правила для него — `travel-earth/AGENTS.md`). Перенос данных — позже, когда Atlas станет основным.

**Данные и доступ** (решено с Грегори, `ROADMAP.md`, раздел 0): своего сервера нет; личное — только на устройстве, наружу ничего без явного действия; вход не обязателен, Google Drive (папка приложения) — только для синхронизации; GitHub — только публичное; каждый модуль объявляет, что отправляет в сеть (поле `sends`), для экрана «Что уходит в сеть».

Полный список того, что нужно платформе (ядро, офлайн, перевод, голос, фото, новые слои), — `ROADMAP.md`.

# Atlas — правила для Claude

Atlas — новая платформа Грегори (создана 2026-10-27): карта-глобус для путешествий + просмотр и правка фото. Собирается заново, по одной функции, из двух проектов, которые остаются рабочими резервными копиями и **не перестраиваются**:

- **travel-earth** (`C:\Users\Grigori\.GitHUB\travel-earth`, GitHub Pages) — карта, слои, экскурсии с аудиогидом, разговорники, фото Commons/Mapillary/свои, галерея с видео и живыми фото. Подробности и все решения Грегори — в его `CLAUDE.md`.
- **photo-editor / Albom** (`E:\.GitHub\photo-editor\repo`) — правка фото: горизонт (OpenCV.js), поворот, перспектива, кадрирование, цвет, шумоподавление, EXIF.

Грегори (2026-10-27): «Не будем гнездить старые проекты — это разрушит их, и на какой-то момент не будет ничего». Старые проекты заморожены: только исправления ошибок. Новое — только в Atlas.

Цель — «площадка, максимально адаптивная для будущих концептов работы с графикой: появилось что-то новенькое — прикрутили». Грегори общается по-русски, тексты интерфейса — для людей, без технических подробностей.

## Устройство: ядро + модули

```
core/      карта, общий стиль, реестр модулей (modules.js), события (events.js),
           настройки (settings.js), окно-панель (panel.js), панель «Слои» (layers-panel.js)
layers/    слои карты
content/   разделы с панелью: Экскурсии, Языки, Мои альбомы, Мои треки
sources/   источники фото
tools/     инструменты окна просмотра (правка фото)
voices/    голоса для чтения
```

- Модуль — файл в своей папке, вызывает `register({...})` из `core/modules.js`; подключается строкой в `MODULES`. Ядро модули по именам не знает.
- **Тяжёлое — только по надобности:** библиотеки и модели модуль грузит в `load()`, при первом включении, а не при старте.
- Модуль сам объявляет, что ему нужно (`needs`: folders, webgpu, network, desktop). **Правило недоступного:** нет возможности на этом устройстве — модуль не показывается; есть возможность, но нет данных — кнопка видна и неактивна (`disabled`). Это примиряет правило photo-editor «ничего не прятать» и решение travel-earth «на телефоне разделы папок не нужны».
- **Связь модулей — только события** (`core/events.js`: `on`/`emit`, последнее значение запоминается); имена событий перечислены в начале файла, новое — дописать туда.
- **Окно — только `createPanel`** (`core/panel.js`): одновременно открыта одна панель, шапка «название · [свои кнопки раздела `addButton`] · свернуть (только окна слева — значком в строку поиска) · закрыть; окно справа (настройки) не сворачивается, только закрывается», свёрнутость помнится; ползунок внизу — высота окна (помнится, двойное нажатие — по содержимому). Свои окна модули не рисуют.
- **Кнопки слоёв — колесо-барабан в боковой панели справа** (слои; разделы с панелью — во втором барабане на том же месте, его открывает лупа справа вверху) (`core/layers-panel.js`, Грегори 2026-10-29, сменило меню как у Windy): панель открывается и прячется треугольником **в правом нижнем углу, поверх ленты фото** (`.wheel-toggle`: размером с другие кнопки, прозрачный фон, без каймы; ◀ — показать, ▶ — спрятать; открытость помнится, `layers.panel`), на телефоне панель смахивается вправо. Барабан как в игровом автомате или выборе даты: **размер кнопок один, меняются промежутки** — в центре самые большие, к краям меньше (`y = R·sin(d·θ)`, видно до 7), кнопки у краёв темнеют; крутится колёсиком и пальцем **по кругу**, у центра притормаживает (`shown()`: `v − 0,7·sin(2πv)/2π`), после прокрутки встаёт кнопкой в центр. **Нажатие по центральной — открыть её столбик, по другой — докрутить в центр и сразу открыть**; столбик слева от барабана, **по центру относительно кнопки**, кнопки прижаты вправо, значок справа; глубина — один щелчок. Барабан: **верх — вровень со строкой поиска, низ — постоянно 76 px от низа окна** при любом размере (Грегори: «нижний ограничь и не трогай даже при сильном сжатии»); на телефоне — от-под поиска до ленты фото. **Цвет по группам** (`tone` в `GROUPS`, переменные `--tone-*`): карты, линии (тропы, дороги), точки (места, транспорт, магазины), фото, погода; **выключено — яркая заливка цвета группы, включено — светлая** (Грегори: «наоборот» — иначе не разобрать группы) и крестик в углу (снимает всё в кнопке и закрывает её столбик); выделенные кнопки столбика — светлой заливкой цвета группы, остальные выделения в панелях — светлым `--active`. **«Карты»** — первая кнопка, в кружке миниатюра текущей карты; в столбике пять карт с миниатюрами (выбранная — в кольце) и под чертой рельеф (раздел `relief`: «Тени и 3D», «Высоты»). Плитки карт внизу больше нет (`core/basemaps.js` — только `setBasemap`). Модуль с видами (`menu`) — своя кнопка (Транспорт, Магазины, Тропы, Велодорожки, Дороги); если название совпадает с разделом — остальные слои раздела в ней под видами (Дороги + Железные дороги). Виды — `core/profiles.js` (`profileMenu`): отмечать можно несколько, пункта «Все…» нет. Где цвет на карте что-то значит — значок кнопки столбика в кольце этого цвета (`color`). Открылась панель настроек — колесо прячется, и наоборот (`closeOpen()`).
- `layers/photos.js` — кружок «Фото» (Грегори, 2026-10-28): «Фото» — снимки Wikimedia Commons, **алгоритм travel-earth** (Грегори, 2026-10-29: «высыпает фотки сразу все… должны быть просто точки и потом миниатюры»): со шкалы «20 км» — только точки (редкая проба: узел сетки на ~180 px — реже прежних 100, это были десятки поисковых запросов ради сотни точек, круг 10 км, по точке на четверть круга), со «3 км» — квадраты тайлов z12+ целиком, **все снимки точками сразу**, потом **миниатюры**, четвертинки переполненных квадратов (500 точек) — последними. **Две очереди, в каждой один запрос за раз** (просьба Wikimedia): поиск (точки) и сведения о снимках (миниатюры) — «поиск занят» касается только поиска, поэтому миниатюры не ждут четвертинок, а начинаются, как только загружены точки основного уровня в кадре. Загрузка начинается по `moveend`, не по `idle` (не ждёт, пока дорисуется подложка). **Найденное помнится на устройстве неделю** (`cacheGet`/`cacheSet`: `commons/cell|probe/<z/x/y>`, `commons/info/<pageid>`) — знакомые места без запросов. Размеры миниатюр — только стандартные Wikimedia (120, 330, 1920; с 2026 нестандартные CDN отклоняет) (Грегори, 2026-10-29: «без миниатюр точки загружаются мгновенно… высыпать все точки, и только потом подгружать миниатюры»): по одной на клетку экрана 64 px (ближайшая к середине; клетка с миниатюрой готова, приблизили — клеток на местности больше), `imageinfo` пачкой до 50 — автор/лицензия/дата; снимок без миниатюры помечается `failed`; с «1 км» — миниатюры 44 px в белой рамке поверх точек (свой источник `photo-commons-thumbs`). **Налезающие точки — один кружок с числом снимков** (Грегори, 2026-10-29: «правило, ограничивающее количество точек на квадрат, нарушать нельзя… на перекрывающихся точках писать просто цифру»): источник `photo-commons` собирает точки ближе 18 px (`cluster`), число — слой `photo-commons-count`, щелчок по кружку — приближение, пока не распадётся. Commons часто отвечает «поиск занят» (`cirrussearch-too-busy`, код 200) и «too many requests» при параллельных запросах — запросы строго по одному, после отказа пауза 1,5 с, вдвое дольше до 15 с. «Снимки улиц» — Mapillary (ключ — открытый Client Token Грегори из travel-earth): линии съёмки с «1 км» (тайлы только z13), точки снимков со «100 м» (только z14) — тяжёлые тайлы, по источнику на уровень, при выключении источники удаляются; щелчок — снимок (Graph API), щелчок по снимку / «Смотреть в плеере» / двойной щелчок по линии — **плеер `viewer.html`** (MapillaryJS 4.1.2, тёмное отдельное окно `atlas-streets`, можно унести на другой монитор), он шлёт `postMessage` с положением и направлением камеры — на карте розовая точка с веером, карта подвигается. «Веб-камеры» — OSM `webcam`/`contact:webcam` (~10 тыс., один запрос QLever на весь мир; точки — со шкалы «100 км» (Грегори 2026-10-29: на глобусе значки сыпались кучей, потом «ограничить видимость 100 км»), значки — со «3 км»), в окне — ссылка, а если она на картинку — кадр. `stats()` — для проверки.
- `core/photo-strip.js` — **лента снимков внизу и галерея** (Грегори, 2026-10-29: «ленту с превью найденных фоток внизу экрана и переходом в альбом в отдельном окне при даблклике; и может у веб-камер тоже»), как в travel-earth: со шкалы «3 км», снимки в кадре слева направо, ушедшие убираются, колесо крутит вбок; внизу от края до края, **поверх** кнопок слева внизу — кнопки не сдвигаются (Грегори, 2026-10-29: «когда кнопки прыгают — очень некрасиво, всегда можно этого избежать»); над лентой поднимается только строка состояния (`body.has-photo-strip`). Источник отдаёт `setStripItems(source, items)` (`{ id, coordinates, thumb, title, full, credit, link, select }`), ядро источники по именам не знает. Щелчок — выделение (розовое кольцо `photo-strip-selected` на карте, рамка в ленте) и окно снимка; двойной щелчок (и по миниатюре на карте) — `gallery.html`, тёмное отдельное окно `atlas-gallery` (список берёт у карты через `window.opener.atlasGallery()`): ← → Home End, свайп, Esc; листание выделяет снимок на карте и подвигает её. В ленте — Commons с миниатюрой и веб-камеры, у которых ссылка ведёт прямо на картинку (в Таллине так почти все — перекрёстки `ristmikud.tallinn.ee`); у остальных камер — страница сайта, превью нет.
- **Разделы с панелью** (`kind: "content"`, папка `content/`; Грегори, 2026-10-29: «берём из Travel Earth Языки, Экскурсии и Мои альбомы», по одному, каждый выкладывается отдельно) — **свой барабан разделов** (Грегори 2026-11-02, после пробы строки кнопок под поиском — «занимает очень много места»): Экскурсии · Языки · Треки · Фото (порядок — `MODULES`) на том же месте справа, что барабан слоёв; **один барабан сменяет другой**; **минимализм** (Грегори: «при первом старте нет ни барабанов, ни окна поиска»): барабан разделов открывает **полупрозрачная лупа справа вверху** (`.search-toggle`, как треугольник) вместе со строкой поиска, слоёв — треугольник справа внизу. **Щелчок — свой барабан (вместо другого), второй щелчок — спрятать** (у лупы — вместе со строкой поиска и открытым разделом: событие `search-exit`). **Лупа одна** («не комильфо» две): открыт поиск — лупа только в строке, а на месте кнопки — **логотип Atlas** в белом кружке, выбран раздел — **значок раздела** в кружке его цвета, сразу у списка раздела (каждый раздел ставит режим поиска уже в `column.home`; у Языков — «Найти язык», Грегори 2026-11-02: «значок языка вообще не приходит») (событие `search-mode` из `core/search.js`); в самой строке поиска ни логотипа, ни значка режима больше нет. Помнится `layers.panel` ("layers"/"content") и `search.open`; на телефоне строка поиска короче на ширину кнопки; верх обоих барабанов и правая панель (настройки) — под лупой. **Столбика у разделов нет** (Грегори: «сразу панели, как экскурсии или языки, в одном окне под окном поиска — проще прокрутка, если список вырастет»): кнопка раздела сразу открывает **панель слева под поиском** со списком (`homeList` из `core/panel.js`: страны, языки — флаг слева; модуль даёт `column.home(ctx)` или `column.panel` + `items()`/`choose(id)`), **выбор файлов — первой строкой списка, прямо по нажатию**: **одинаковой строкой с «+»** (Грегори 2026-11-03: «разные кнопки + открыть»): «+ Открыть трек…» у треков (их список — сама панель), «+ Добавить папку…» (или «Открыть мою папку…» после перезапуска) у фото (на компьютере; в настройках тоже осталось); у списка страны (Экскурсии, Альбомы) — стрелка «Все страны». Колесо при левой панели на компьютере не прячется, на телефоне прячется; кнопка раздела светлая, пока панель открыта, её крестик закрывает панель. **В строке поиска — значок режима** (Грегори: «без окна поиска не обойтись; после выбора режима должен появляться значок»): `setSearchMode({ icon, title, placeholder, filter, exit })` из `core/search.js`, ввод ищет внутри раздела на каждую букву, **значок режима — на кнопке справа вверху вместо логотипа** (Грегори 2026-11-02; цвет — `tone` раздела), её второй щелчок — выйти из режима и закрыть панель вместе с поиском. Связь разделов — события `languages-wanted` / `languages` / `language-open` (экскурсия находит разговорник своей страны). Данные — `core/repo.js` (папки репозитория travel-earth: дерево — GitHub API, помнится час, запасной список — jsDelivr; файлы — с сайта travel-earth с `?v=хэш`, прочитанные помнятся по хэшу), голос — `core/speech.js` (лучший голос языка, чтение по предложениям, «разблокировка» на Android), флаги — `core/flags.js` (flagcdn). Порядок кнопок разделов в барабане — как в `MODULES` (модули грузятся параллельно).
- `content/languages.js` — **Языки**: разговорники папки «Языки» (до трёх файлов на язык — вкладки «Разговорник / Словарь / Общие фразы», язык группируется по коду `Язык:`), столбик — языки с флагами, панель — «О языке», разделы (открыты первый и первый с фразами), фраза — щелчок читает её голосом языка, плеер «все подряд» (раздел, по-русски, на языке; щелчок по фразе во время чтения — продолжить с неё), «свернуть все»; **стрелка назад** слева от плеера, как у экскурсии (Грегори 2026-11-03) — к списку языков, а открытый из экскурсии — к ней (`language-open` с `back`); режим поиска «Найти фразу». Формат файла — как в travel-earth (промт `Языки/_Промт — как написать разговорник.md`).
- `content/tours.js` — **Экскурсии**: файлы папки «Экскурсии» (формат и разбор — как `parseTour` travel-earth, промт `Экскурсии/_Промт — как написать экскурсию.md`), столбик — страны с флагами и числом экскурсий, панель — список страны (группы по «Группа:»/«Город:» первыми), экскурсия в той же панели (стрелка назад к списку): «Об экскурсии» (регион, маршрут, идея, кнопка «Разговорник: …»), пункты — у остановок (разделы с «Место:») красный номер, факты строкой, точки, особенности, абзацы, плашки «Справка» / «Из источника» с «Послушать», источники. На карте — только открытая экскурсия: номера (`tour-stops`/`tour-num`), пунктир у поездки с «Маршрут:», выделенная — розовое кольцо; выделение в обе стороны, перелёт со сдвигом в свободную часть кадра (справа от панели / под ней). Сохранение — как в photo-editor: исходник — в `[Originals]` рядом (только при первой правке), снимок переписан, копия — в «…-Albom» поездки (первая папка внутри своей; есть «… -Albom» с пробелом — она); правка снимка из самого «-Albom» — без копии; «Оригинал» — исходник обратно, `[Originals]` и копия убраны. **EXIF** (`tools/jpeg.js`) переносится из исходника целиком (photo-editor писал только камеру, дату и место): Orientation = 1, PixelX/YDimension — новый размер. Доступ к папке окно галереи берёт само из IndexedDB `albums/dirs` и само просит запись по «Сохранить» (так браузер разрешает; в проверке — `atlasGalleryRoots()` окна карты); после записи окно карты обновляет миниатюру (`atlasGallerySaved`). `tools/rotate.js` — **поворот**: на 90° влево/вправо, зеркало, точный угол ±45° (шаг 0,1°, щелчок по числу — 0°), «Горизонт», сетка (мелкая 1/30 и синие трети, сама видна, пока тянешь); поворот — по-настоящему, края срезает рамка — самый большой кадр тех же пропорций внутри повёрнутого (`cropScale`), за рамкой затемнено. При открытии правки **ничего не запускается само** (Грегори 2026-11-04) — ни горизонт, ни цвет, ни шум: снимок как в файле, всё — только по кнопкам. `tools/horizon.js` — **горизонт** (алгоритм photo-editor: Canny + Hough, кластеры по углу и высоте, самая верхняя ровная длинная линия; больше 5° — «приняли что-то другое»), OpenCV.js 4.9.0 грузится по первому нажатию; **`cv` нельзя отдавать в `resolve`** — у него `then`, обещание зовёт его бесконечно и страница падает (поймано на снимках Грегори, 2026-11-03). `tools/crop.js` — **кадр** (2026-11-04): кнопка показывает **общую рамку** (она в `editor.js`, ею пользуются все инструменты — правило photo-editor: своих рамок инструменты не строят) с уголками, над полосой — пропорции «Как снимок / Свободно / 1:1 / 4:5 / 4:3 / 16:9 / 9:16» (`ASPECTS`, помнятся `edit.aspect`); рамка — в точках превью от середины снимка, уголок тянется (напротив — неподвижный), за середину — двигается; **за края снимка с учётом поворота не выходит** (`fits`/`onPhoto`): уголок упирается, рамка скользит вдоль края по каждой оси (`most`); повернули — нетронутая рамка снова самая большая (`biggest`), тронутая уменьшается вокруг середины (`shrink`); повороты на 90° и зеркало — заново. Сохраняется то, что в рамке (`kept()`: без рамки — весь снимок без пустых углов). `tools/perspective.js` — **перспектива** (2026-11-04): кнопка показывает четыре ручки по углам снимка (контур синий, сетка видна сама), угол тянется куда угодно в пределах ещё одного снимка от края, только выпуклым четырёхугольником (`convex`); `ed.quad` — куда встают углы снимка (до поворота на `angle`), снимок искажается **по-настоящему**: на экране — сетка 16×16 клеток по два натянутых треугольника (`drawWarped`, быстро), при сохранении — точный расчёт каждой точки обратно в исходник с усреднением четырёх соседей (`warpOut`, проективное преобразование «квадрат → четырёхугольник» Хекберта, `homography`/`invert`); порядок: перспектива, потом точный угол, потом рамка. Рамка и «самая большая рамка» считаются внутри искажённого и повёрнутого четырёхугольника (`onPhoto`, `biggest` — перебором вокруг его середины). Повороты на 90° и зеркало **несут перспективу с собой**; **зеркало — всегда слева направо, как видно** (после поворота на 90° одно переключение `flip` отразило бы сверху вниз — поворот меняется на обратный, `q = 4 − q`). «Перспектива — как было» — кнопка рядом (неактивна, пока не тронули). В правке подпись сверху пропускает нажатия к холсту (ручки под ней тянутся). Полоса инструментов и пропорции — в одном блоке `.edit-dock` внизу: в узком окне полоса переносится в две строки, снимок уменьшается над ней (`dock.offsetHeight`). **Шум и цвет** (2026-11-04, `tools/noise.js`, `tools/color.js`, общие плитки — `tools/variants.js`): кнопка открывает над полосой **плитки вариантов** — маленький снимок с вариантом (с уже выбранным другим инструментом) и подпись, щелчок — примерить, ← → — соседний; над полосой одна строка за раз (`ed.panel`: пропорции, шум, цвет). Варианты — как в photo-editor: шум «Выкл / Лёгкое / Среднее / Сильное» (`bilateralFilter` OpenCV.js — грузится при первом выборе, `opencv()` из `horizon.js`; на плитках окрестность меньше), цвет «Оригинал / Авто / Контраст+ / Ч/Б / Тепло» (автоконтраст по каналам — края гистограммы, насыщенность от серого, тепло — красный выше, синий ниже); по умолчанию «Оригинал» и «Выкл». Это **обработка пикселей** (`api.filter({ key, order, off, apply })`, значения — `ed.values`): превью пересчитывается (`refilter`, кружок, пока считается), при сохранении — по всему снимку в полный размер **до** поворота, перспективы и рамки (гистограмма по всему кадру — иначе цвет менялся бы от рамки, опыт photo-editor); шум раньше цвета. Дальше по плану: сведения о снимке (дата, место, «в альбом», «удалить»), увеличение ×2.

В панели — свой раздел «Тропы» (`group: "trails"`): «Тропы» и «Велодорожки» с меню «Все велодорожки / Веломаршруты / Маунтинбайк» (Грегори, 2026-10-28; вид помнится, `trails.cycling.profile`); у «Троп» меню по значимости «Все / Международные / Национальные / Региональные / Местные» (цвет линии = значимость; фильтр по `rank` только своим линиям с зума 11 — картинки издалека показывают все тропы, Грегори 2026-10-28; `trails.hiking.profile`). `makeKind()` даёт управляемый слой (`setRanks`), модули собираются из них. Значки (Грегори, 2026-10-29): у «Троп» — пешеход с рюкзаком и палкой, по картинке Грегори (босые стопы в любом виде «похожи на кальмара» — не возвращать), у видов — обувь сбоку от тяжёлой к лёгкой (`SHOES`: международные — высокий ботинок, национальные — пониже, региональные — кроссовок, местные — носок; кроссовок и носок — по картинкам Грегори); у «Маунтинбайка» — велосипед в гору на наклонной полоске дороги.
- `layers/terrain.js` — «Рельеф» одной кнопкой: тени склонов + 3D (Грегори, 2026-10-28: «объединить Рельеф с 3D-рельефом»), «Высоты» — горизонтали с подписями (кнопка переименована Грегори 2026-10-28; maplibre-contour грузится по надобности), железные дороги. `layers/outdoor.js` — пляжи, сёрфинг (+ `surf-spots.json` — кайт-споты Грегори), значки у троп (`group: "hidden"`, включаются сами вместе с любыми тропами). Запросы к QLever — `core/qlever.js`.
- `layers/roads.js` — «Дороги» (Грегори, 2026-10-28): тайлы OpenFreeMap `transportation`, цвет и толщина по классу, грунтовые (`surface=unpaved`, `track`) — пунктиром, тоннели — полупрозрачным пунктиром; виды Автомагистрали / Главные / Местные / Грунтовые — значки дорожными знаками (Грегори, 2026-10-29: «значки машин заменим на дорожные знаки»: автомагистраль — две проезжие части вдаль, без моста (с мостом «похож на домик»); главная дорога; пересечение со второстепенной; неровная дорога; у «Железных дорог» — крупный паровоз без треугольника), у кружка — машина (`roads.profile`), повторное включение меняет фильтр.
- `layers/weather.js` — «Ветер» (Open-Meteo: сетка в кадре кратна шагу, ответы на час; сила в м/с — Грегори 2026-10-28: «измени показания ветра на m/s»; цвет по силе как у Windy, пороги пересчитаны в м/с) и «Осадки» (RainViewer: 8 кадров за 2 часа анимацией; бесплатно только до зума 7). В панели — раздел «Погода».
- **Перенос правок travel-earth 2026-10-28:** слой пеших маршрутов называется **«Тропы»** (Грегори: «замени везде пешие прогулки на тропы»). Значки у троп: щиты/указатели/карты/инфостенды с тегом `image` — оранжевое кольцо вокруг обычного значка (`outdoor-<kind>-photo`, признак `hasPhoto` из того же запроса QLever), фото — в окне по щелчку (`photoUrl`: ссылка или `File:` → Commons `Special:FilePath`); капли воды — отдельный слой `trail-poi-water`, со шкалы «30 м» и крупнее. Транспорт: значок в булавке 30 px вместо 22; вокзалы и станции фуникулёров видны со «3 км» — слой `places-transport-far` из QLever (квадраты 1°) до зума 12, дальше тайлы; станции фуникулёров (station=funicular / funicular=yes) — зелёная булавка с наклонённым вагончиком, в тайлах узнаются по id (`funicularIds`). Канатные дороги (Грегори: «в Atlas нет канатных дорог, в Travel Earth в Барселоне были с линиями»): тросы и рельсы фуникулёров — зелёный слой `places-lift-line`; станции канаток — по id троса из OSM API (`way/…/full`, узлы aerialway=station) в слое `places-cable` до зума 14, дальше — из тайлов; в окне — «Станция канатной дороги» (`kindOf` смотрит class aerialway раньше subclass). **Издалека, как фуникулёры** (Грегори, 2026-10-28: «подними по видимости канатные дороги до фуникулёров»): со шкалы «3 км» до зума 12 тросы (`places-cable-far-line`, WKT из QLever → `wktLines`) и станции канаток (subclass `cable` в `places-transport-far`) приходят из QLever квадратом 1° (`cableLoader`); у вида поле `far` включает "cable".
- **Транспорт — меню видов, как у «Магазинов»** (Грегори, 2026-10-28: «каждый транспорт отдельно выпадающим списком»): `TRANSPORT_PROFILES` в `layers/places.js` — Весь транспорт, Поезда и вокзалы, Метро, Трамваи, Автобусы, Паромы, Фуникулёры и канатные дороги, Аэропорты; у вида поля `subclasses`/`stops`/`airports`/`far` (дальние станции из QLever)/`cable` (тросы и станции канаток)/`lifts`/`rail`; выбранный вид помнится (`places.transport.profile`).
- **Окна на карте — только через `track()` из `core/popups.js`:** все закрываются при движении карты (кроме движения навигации за мной — `easeTo(…, { navFollow: true })`, Грегори 2026-11-04: «окно Сюда постоянно сбрасывается»), первый щелчок при открытом окне только закрывает. `map.transform` в MapLibre 6 нет — «точка на Земле?» проверяется через `project(unproject(p))`.

### Ревизия интерфейса (Грегори 2026-11-05)
- «Сюда» в окнах на карте — **только при включённой навигации** (любой режим строки); без неё окно — только сведения об объекте. Первое «Сюда» и выбор точки показывают весь путь (`fitPath` в `core/route.js`: я + цель), пришедший путь по дорогам — тоже весь на экран.
- Цель на карте — **крупный синий флажок финиша** (`.go-flag`, 44×52, цвет навигации), не красная капля.
- Телефон: **касание уже выбранного снимка** (лента, клетка альбома, снимок на карте с открытым окном) — галерея; двойное касание не требуется (`touchUI()` из `core/photo-strip.js`).
- Телефон: **долгое нажатие на кнопку — её подпись** (`title`) плашкой (`core/touch-tip.js`); само нажатие тогда не срабатывает.
- ⓘ источников при запуске не раскрывается (MapLibre раскрывает сам — `app.js` не даёт), раскрытый текст растёт вверх, ⓘ не двигается.
- **Esc на компьютере = «Назад» телефона** (`core/back.js`): закрывает последнее открытое. Кто сам обработал Esc — `preventDefault`.
- Строка поиска при наборе: первой строкой **«Искать «…» везде — Enter»** (`.search-everywhere`), ниже — совпадения из истории. Для найденных результатов строки нет.
- Включённые кнопки колеса — кроме светлой заливки **кольцо цвета раздела и галочка в углу**.
- Язык подписей («Ру») — кнопка столбика справа под логотипом (2026-11-06), меню — сбоку от неё; в строке поиска её нет.
- Строка состояния (`#status`) — **плашкой** (фон окна, тень), пустая не видна.
- Галерея: ▶ играет **в окне** (окно можно унести на другой монитор/телевизор), во весь экран — отдельной кнопкой; выход из полного экрана показ не останавливает.

### Столбик под логотипом и навигация (Грегори 2026-11-06)
- **Столбик справа сразу под логотипом** (`core/dock.js`, «мёртвая зона правого края при открытых барабанах»): шестерёнка, язык подписей, затем **значки включённых режимов** (навигация; есть цель — крупная красная стрелка к ней: щелчок показывает/прячет карточку пути; открытые разделы — щелчок показывает или сворачивает их окно). Виден, пока открыт поиск или любой барабан (и не открыто окно настроек); барабан, доходя сюда, уходит под него. **На телефоне столбик лежит поверх шапки окна раздела — так и задумано** (Грегори 2026-11-06: «сначала нужно свернуть барабаны, теперь это стало очевидно»): окно не сужать. Слева внизу остались навигация и компас (ⓘ и шкала — в линию с нижней кнопкой). **В строке поиска — только лупа** (и крестик очистки при наборе): значков свёрнутых окон и стрелки пути в ней больше нет.
- **Кнопка справа вверху — по кругу: всё (поиск + барабан) → без строки поиска (барабан остаётся) → закрыто → всё.** Закрыто и режима нет — **только красная капля** из логотипа, крупно (`.search-toggle.drop`); режим есть — его цветной значок.
- **Навигация:** пока карточка пути видна (событие `route-card`), карта за мной **не ходит** (`nav-hold`), на экране весь **оставшийся** путь (`route-show`; есть сеть и способ выбран — путь пересчитывается от того места, где я); пройденная часть линии стирается (от ближайшей точки пути, не дальше 60 м). Карточку свернули — **сразу ко мне, без задержки**. Сдвинул карту рукой — обратно через **15 с** (было 10). При начале навигации сообщений нет (только запрет доступа).
- Окна на карте **целиком на экране** (`keepOnScreen` в `core/popups.js`: выросло и не влезает — карта чуть сдвигается, окно не закрывается); «Сюда» — с той стороны окна, где объект (по `maplibregl-popup-anchor-*`); крестик окна — крупный, толстой линией.
- Галерея: **описание снимка — за кнопкой ⓘ** (`.info-btn`), каждый снимок открывается чистым.
- Компьютер: строка поиска — **шириной с окно раздела (400 px) и вровень с ним** слева.

### Лупа, флажок, версия (Грегори 2026-11-06, вечер)
- **Логотип на кнопке справа вверху больше не используется — там лупа** (на белом кружке при открытом поиске, полупрозрачная при спрятанном); (капля и «три положения» отменены — см. ниже). **Есть цель пути — на этой кнопке крутящаяся красная стрелка к цели**, а значок навигации в столбике — **флажок финиша** (щелчок по нему показывает/прячет карточку).
- В барабане разделов первой — **«Поиск места»** (лупа): из режима раздела в обычный поиск мест (`search-plain`); навигация при этом работает, «Куда» возвращает кнопка «Навигация».
- Столбик под кнопкой — плотно (промежуток 4 px), значки ровно по центру кружков.
- Подписи кнопок «Свернуть» — без пояснений; подсказка по долгому нажатию — от 0,7 с.
- ⓘ раскрыта — **шириной до 320 px**, первой строкой — **«Версия <коммит> · <дата>»** (GitHub API по первому нажатию; без сети — «Обновлено <дата страницы>»).

### Два положения кнопки, окна без «–» (Грегори 2026-11-06, ночь) — отменяет часть пунктов выше
- **При старте всё закрыто** (барабаны, поиск, окна — с прошлого раза не восстанавливаются), на кнопке справа вверху — **логотип из travel-earth** (`icons/start-logo.png`), **только до первого щелчка**. Капли больше нет. Дальше на кнопке — значок выбранного раздела, без режима — лупа, есть цель — стрелка.
- Кнопка — **два положения**: закрыто → поиск и барабан разделов; открыто что-то (поиск или барабан разделов) → **свернуть всё**. Барабан разделов при старте — «Поиском места» в центре.
- **У окон слева нет «–»**: сворачивает и разворачивает окно его значок в столбике под кнопкой (как флажок — карточку пути); в шапке только «закрыть». На телефоне окно — **шириной со строку поиска**: справа столбик и барабан, окно под них не заходит.
- Подсказки при наведении и долгом нажатии остаются. **Сами по себе после нажатия подсказки не выскакивают**: подпись центральной кнопки барабана — только после прокрутки (колёсико, палец) и при наведении, не после щелчка по кнопке и не при открытии барабана.

## Стиль — один на всё

- Все цвета, шрифт, размеры, скругления — переменные в `core/style.css`. Модуль своих цветов не заводит.
- Общие элементы — один CSS-класс (`.btn` и т. п.), без точечных переопределений по месту.
- Значки — монохромные (`currentColor`), с тонким кантом вместо тени; светлым значкам — кант контрастного цвета.
- **Значки — максимально большие, почти во всю кнопку; размер кнопки не меняется** (Грегори 2026-11-05: «всё начинается с еле видных значков… это становится навязчивой проблемой»). Одно CSS-правило на все маленькие кнопки окон, списков и карточек (`.panel-btn`, `.pb-btn`, `.search-delete`, кнопки строки поиска, `.go-way`, `.go-close` — значок = кнопка − 4 px), в галерее — `.player-btn`, `.edit-tool`, `.bar-btn`; крестики — линией 2,2–2,4, не буквой «×». Новую кнопку со значком — в это правило.
- Нажатая/выделенная кнопка — светлая заливка (`--active`, тёмный текст), не белый и не прозрачный фон.
- Карта и панели над ней — светлые; окно просмотра и правки фото — тёмное.

## Данные

Экскурсии, Языки и Альбомы пока живут в репозитории **travel-earth** — Atlas читает их оттуда (GitHub API / raw), ChatGPT продолжает писать туда же (правила для него — `travel-earth/AGENTS.md`). Перенос данных — позже, когда Atlas станет основным.

**Данные и доступ** (решено с Грегори, `ROADMAP.md`, раздел 0): своего сервера нет; личное — только на устройстве, наружу ничего без явного действия; вход не обязателен, Google Drive (папка приложения) — только для синхронизации; GitHub — только публичное; каждый модуль объявляет, что отправляет в сеть (поле `sends`), для экрана «Что уходит в сеть».

Полный список того, что нужно платформе (ядро, офлайн, перевод, голос, фото, новые слои), — `ROADMAP.md`.

# Atlas — правила для Claude

Atlas — новая платформа Грегори (создана 2026-10-27): карта-глобус для путешествий + просмотр и правка фото. Собирается заново, по одной функции, из двух проектов, которые остаются рабочими резервными копиями и **не перестраиваются**:

- **travel-earth** (`C:\Users\Grigori\.GitHUB\travel-earth`, GitHub Pages) — карта, слои, экскурсии с аудиогидом, разговорники, фото Commons/Mapillary/свои, галерея с видео и живыми фото. Подробности и все решения Грегори — в его `CLAUDE.md`.
- **photo-editor / Albom** (`E:\.GitHub\photo-editor\repo`) — правка фото: горизонт (OpenCV.js), поворот, перспектива, кадрирование, цвет, шумоподавление, EXIF.

Грегори (2026-10-27): «Не будем гнездить старые проекты — это разрушит их, и на какой-то момент не будет ничего». Старые проекты заморожены: только исправления ошибок. Новое — только в Atlas.

Цель — «площадка, максимально адаптивная для будущих концептов работы с графикой: появилось что-то новенькое — прикрутили». Грегори общается по-русски, тексты интерфейса — для людей, без технических подробностей.

## Устройство: ядро + модули

```
core/      карта, общий стиль, реестр модулей (modules.js), события (events.js),
           настройки (settings.js), окно-панель (panel.js), панель «Слои» (layers-panel.js)
layers/    слои карты
sources/   источники фото
tools/     инструменты окна просмотра (правка фото)
voices/    голоса для чтения
```

- Модуль — файл в своей папке, вызывает `register({...})` из `core/modules.js`; подключается строкой в `MODULES`. Ядро модули по именам не знает.
- **Тяжёлое — только по надобности:** библиотеки и модели модуль грузит в `load()`, при первом включении, а не при старте.
- Модуль сам объявляет, что ему нужно (`needs`: folders, webgpu, network, desktop). **Правило недоступного:** нет возможности на этом устройстве — модуль не показывается; есть возможность, но нет данных — кнопка видна и неактивна (`disabled`). Это примиряет правило photo-editor «ничего не прятать» и решение travel-earth «на телефоне разделы папок не нужны».
- **Связь модулей — только события** (`core/events.js`: `on`/`emit`, последнее значение запоминается); имена событий перечислены в начале файла, новое — дописать туда.
- **Окно — только `createPanel`** (`core/panel.js`): одновременно открыта одна панель, шапка «название · свернуть · закрыть», свёрнутость помнится. Свои окна модули не рисуют.
- **«Слои» — меню как у Windy** (`core/layers-panel.js`, Грегори 2026-10-28 со скриншотами): справа вверху круглая кнопка «Слои» → столбик кружков **без подписей** (название — во всплывающей подсказке); без окна и заголовка. Щелчок по кружку — слева столбик кнопок, прижатых вправо, значок справа от названия; **глубина — один щелчок**, вложенных меню нет. Кружок раздела (`group` модуля, порядок — `GROUPS`: places «Места» (с пляжами и сёрфингом), trails, roads, relief, weather «Погода» (тучка с солнцем), photo «Фото» (камера), без раздела — «Ещё»; `hidden` не показывается) содержит переключатели слоёв; **модуль с видами (`menu`) — свой кружок** (Транспорт, Магазины, Тропы, Велодорожки, Дороги); если его название совпадает с названием раздела — остальные слои раздела в том же кружке под видами (Дороги + Железные дороги). Виды — `core/profiles.js` (`profileMenu`): **отмечать можно несколько, пункта «Все…» нет** (Грегори: иначе пришлось бы снимать отметки по одной); снят последний вид — слой выключается; выбор — массив в настройках. **Крестик справа вверху кружка** (виден, когда в нём что-то включено) снимает всё в кружке. **Где цвет на карте что-то значит** (значимость троп, класс дорог, вид транспорта, флажки мест, фото) — значок кнопки в кольце этого цвета (`color` у вида или модуля), названия короткие. Столбик кнопок после выбора не закрывается (щелчок мимо или Esc). Кружок залит `--active`, если в нём что-то включено; кнопка «Слои» — если включён любой видимый слой. Пока столбик открыт, кнопки карты справа внизу скрыты (`body.layers-open`). Открылась панель (настройки) — столбик закрывается, и наоборот (`closeOpen()`).
- `layers/photos.js` — кружок «Фото» (Грегори, 2026-10-28): «Фото» — снимки Wikimedia Commons, **алгоритм travel-earth** (Грегори, 2026-10-29: «высыпает фотки сразу все… должны быть просто точки и потом миниатюры»): со шкалы «20 км» — только точки (редкая проба: узел сетки на ~100 px, круг 10 км, по точке на четверть круга), со «3 км» — квадраты тайлов z12+ целиком, по снимку на клетку сетки 4×4 + миниатюра и автор/лицензия/дата (`imageinfo`), квадрат с 500 точками делится на четыре; с «1 км» — миниатюры 44 px в белой рамке поверх точек. Commons часто отвечает «поиск занят» (`cirrussearch-too-busy`, код 200) и «too many requests» при параллельных запросах — запросы строго по одному, после отказа пауза 1,5 с, вдвое дольше до 15 с. «Снимки улиц» — Mapillary (ключ — открытый Client Token Грегори из travel-earth): линии съёмки с «1 км» (тайлы только z13), точки снимков со «100 м» (только z14) — тяжёлые тайлы, по источнику на уровень, при выключении источники удаляются; щелчок — снимок (Graph API), щелчок по снимку / «Смотреть в плеере» / двойной щелчок по линии — **плеер `viewer.html`** (MapillaryJS 4.1.2, тёмное отдельное окно `atlas-streets`, можно унести на другой монитор), он шлёт `postMessage` с положением и направлением камеры — на карте розовая точка с веером, карта подвигается. «Веб-камеры» — OSM `webcam`/`contact:webcam` (~10 тыс., один запрос QLever на весь мир), в окне — ссылка, а если она на картинку — кадр. `stats()` — для проверки.
- **Сеть:** модуль с полем `sends` подчиняется режиму «без сети» и запрету в настройках (`allowed()` в `modules.js`); запрещённый — кнопка видна и неактивна. Свои запросы в сеть модуль делает только в `enable`/`load`, не при старте.
- **Большие файлы (модели, голоса) — только через `model()` из `core/storage.js`:** скачиваются один раз, видны и удаляются в настройках. Мелкие кэши — `cacheGet`/`cacheSet`.
- **Настройки — только `core/settings.js`** (ключи `atlas.*`), чтобы выгрузка в файл забирала всё.
- Без сборщика: обычные ES-модули, библиотеки с unpkg с точной версией.

## Карта (core)

- `core/basemaps.js` — подложки и переключатель-плитка (5 карт; «Светлую» Грегори убрал 2026-10-25). Смена — `setStyle(…, { diff: false })` и событие `basemap` (`dark` — для светлых подписей своих значков). После смены стиля всё своё ставится заново по `style.load`.
- `core/labels.js` — язык подписей (`coalesce(name:xx, name)`), кнопка — внутри строки поиска; `uiLanguage()` — язык ответов поиска и описаний.
- `core/search.js` — поиск Nominatim (только по Enter/лупе — правила Nominatim), история-избранное. Это модуль-служба (`kind: "service"`, `sends`) — подчиняется режиму «без сети».
- Наклон карты — до 65° (`maxPitch` в app.js; стандарт MapLibre 60°, Грегори 2026-10-28: «ещё на 5 градусов»).
- Строка источников свёрнута в ⓘ (удалять нельзя — лицензии).
- `core/controls.js` — шкала (подписи MapLibre по-русски через `locale` в app.js), «Где я» (слежение помнится), звёздное небо (холст под прозрачной картой; без мерцания при «меньше движения» в системе). Столбик справа внизу снизу вверх: настройки, «+ −», компас, «Где я».
- `core/place-info.js` — окно места по щелчку: значок/подпись карты → название, вид, Википедия, часы, сайт; пустое место → координаты (копируются) и адрес; мимо глобуса — ничего. Служба с `sends`.
- `layers/places.js` — категории мест: шесть модулей `places/*` с `group: "places"` (в панели — раздел «Места»; можно несколько сразу — Грегори 2026-10-28; у каждой категории свой слой `places-poi-<id>`, общая подсказка о зуме), тайлы OpenFreeMap `poi`, флажки с белым кантом (не тенью), транспорт — цвет по виду, аэропорты со «5 км», остановки со «100 м»; у магазинов — `menu` с профилями. Свои слои — `claimLayers()`, окно по флажку — `featureContent()` из place-info.
- `layers/trails.js` — тропы (Waymarked Trails): картинки со «20 км» до зума 11, свои линии с номерами с 11, **с 14 — полная геометрия** маршрутов в кадре из `details/relation` (сервер упрощает `list/segments` сам — `ST_SimplifyVW(1000)`, точка ~100 м, параметра нет; Грегори 2026-10-27: «можно ли сделать больше точек?»). Полная геометрия кэшируется (`cacheSet`), упрощённые отрезки такого маршрута прячутся. `by_area` отдаёт не больше 100 маршрутов — такой квадрат делится на четыре (до 1/8). Проверка — `stats()` модуля. В панели — свой раздел «Тропы» (`group: "trails"`): «Тропы» и «Велодорожки» с меню «Все велодорожки / Веломаршруты / Маунтинбайк» (Грегори, 2026-10-28; вид помнится, `trails.cycling.profile`); у «Троп» меню по значимости «Все / Международные / Национальные / Региональные / Местные» (цвет линии = значимость; фильтр по `rank` только своим линиям с зума 11 — картинки издалека показывают все тропы, Грегори 2026-10-28; `trails.hiking.profile`). `makeKind()` даёт управляемый слой (`setRanks`), модули собираются из них.
- `layers/terrain.js` — «Рельеф» одной кнопкой: тени склонов + 3D (Грегори, 2026-10-28: «объединить Рельеф с 3D-рельефом»), «Высоты» — горизонтали с подписями (кнопка переименована Грегори 2026-10-28; maplibre-contour грузится по надобности), железные дороги. `layers/outdoor.js` — пляжи, сёрфинг (+ `surf-spots.json` — кайт-споты Грегори), значки у троп (`group: "hidden"`, включаются сами вместе с любыми тропами). Запросы к QLever — `core/qlever.js`.
- `layers/roads.js` — «Дороги» (Грегори, 2026-10-28): тайлы OpenFreeMap `transportation`, цвет и толщина по классу, грунтовые (`surface=unpaved`, `track`) — пунктиром, тоннели — полупрозрачным пунктиром; меню «Все дороги / Автомагистрали и скоростные / Главные дороги / Грунтовые» (`roads.profile`), повторное включение меняет фильтр.
- `layers/weather.js` — «Ветер» (Open-Meteo: сетка в кадре кратна шагу, ответы на час; сила в м/с — Грегори 2026-10-28: «измени показания ветра на m/s»; цвет по силе как у Windy, пороги пересчитаны в м/с) и «Осадки» (RainViewer: 8 кадров за 2 часа анимацией; бесплатно только до зума 7). В панели — раздел «Погода».
- **Перенос правок travel-earth 2026-10-28:** слой пеших маршрутов называется **«Тропы»** (Грегори: «замени везде пешие прогулки на тропы»). Значки у троп: щиты/указатели/карты/инфостенды с тегом `image` — оранжевое кольцо вокруг обычного значка (`outdoor-<kind>-photo`, признак `hasPhoto` из того же запроса QLever), фото — в окне по щелчку (`photoUrl`: ссылка или `File:` → Commons `Special:FilePath`); капли воды — отдельный слой `trail-poi-water`, со шкалы «30 м» и крупнее. Транспорт: значок в булавке 30 px вместо 22; вокзалы и станции фуникулёров видны со «3 км» — слой `places-transport-far` из QLever (квадраты 1°) до зума 12, дальше тайлы; станции фуникулёров (station=funicular / funicular=yes) — зелёная булавка с наклонённым вагончиком, в тайлах узнаются по id (`funicularIds`). Канатные дороги (Грегори: «в Atlas нет канатных дорог, в Travel Earth в Барселоне были с линиями»): тросы и рельсы фуникулёров — зелёный слой `places-lift-line`; станции канаток — по id троса из OSM API (`way/…/full`, узлы aerialway=station) в слое `places-cable` до зума 14, дальше — из тайлов; в окне — «Станция канатной дороги» (`kindOf` смотрит class aerialway раньше subclass). **Издалека, как фуникулёры** (Грегори, 2026-10-28: «подними по видимости канатные дороги до фуникулёров»): со шкалы «3 км» до зума 12 тросы (`places-cable-far-line`, WKT из QLever → `wktLines`) и станции канаток (subclass `cable` в `places-transport-far`) приходят из QLever квадратом 1° (`cableLoader`); у вида поле `far` включает "cable". Подсказка «Приблизьте карту» снимается, как только что-то видно, не дожидаясь всех плиток.
- **Транспорт — меню видов, как у «Магазинов»** (Грегори, 2026-10-28: «каждый транспорт отдельно выпадающим списком»): `TRANSPORT_PROFILES` в `layers/places.js` — Весь транспорт, Поезда и вокзалы, Метро, Трамваи, Автобусы, Паромы, Фуникулёры и канатные дороги, Аэропорты; у вида поля `subclasses`/`stops`/`airports`/`far` (дальние станции из QLever)/`cable` (тросы и станции канаток)/`lifts`/`rail`; выбранный вид помнится (`places.transport.profile`).
- **Окна на карте — только через `track()` из `core/popups.js`:** все закрываются при движении карты, первый щелчок при открытом окне только закрывает. `map.transform` в MapLibre 6 нет — «точка на Земле?» проверяется через `project(unproject(p))`.

## Стиль — один на всё

- Все цвета, шрифт, размеры, скругления — переменные в `core/style.css`. Модуль своих цветов не заводит.
- Общие элементы — один CSS-класс (`.btn` и т. п.), без точечных переопределений по месту.
- Значки — монохромные (`currentColor`), с тонким кантом вместо тени; светлым значкам — кант контрастного цвета.
- Нажатая кнопка — приглушённая заливка (`--active`), не белый и не прозрачный фон.
- Карта и панели над ней — светлые; окно просмотра и правки фото — тёмное.

## Данные

Экскурсии, Языки и Альбомы пока живут в репозитории **travel-earth** — Atlas читает их оттуда (GitHub API / raw), ChatGPT продолжает писать туда же (правила для него — `travel-earth/AGENTS.md`). Перенос данных — позже, когда Atlas станет основным.

**Данные и доступ** (решено с Грегори, `ROADMAP.md`, раздел 0): своего сервера нет; личное — только на устройстве, наружу ничего без явного действия; вход не обязателен, Google Drive (папка приложения) — только для синхронизации; GitHub — только публичное; каждый модуль объявляет, что отправляет в сеть (поле `sends`), для экрана «Что уходит в сеть».

Полный список того, что нужно платформе (ядро, офлайн, перевод, голос, фото, новые слои), — `ROADMAP.md`.

## Установка и обновление

- Основной запуск — с GitHub Pages (https://gregory-gittools.github.io/atlas/), установка — кнопкой в настройках (`core/install.js`): не в Edge кнопка открывает `microsoft-edge:…?install`, в Edge — установка браузера; `?install` сразу открывает настройки. Тексты — для людей; «Установка и удаление вручную» под кнопкой (удалять через Параметры → Приложения: программа записана в Windows). Всё это — решения Грегори из travel-earth (2026-10-04).
- Значки — `tools/make-icons.py` (Pillow): глобус с красной меткой, отличается от travel-earth.
- `sw.js` — сначала сеть, потом кэш: в сети всегда свежий код (без `?v=` в адресах), без сети — открывавшееся раньше. Сервис-воркер работает только на https и localhost.

# Atlas

Карта-глобус для путешествий и работа с фотографиями — в одном приложении. Экскурсии с аудиогидом, разговорники, свои фото и общедоступные снимки на карте, просмотр и правка фото.

Новая версия, которая собирается из двух проектов:
[Travel Earth](https://github.com/Gregory-GitTools/travel-earth) и [photo-editor](https://github.com/Gregory-GitTools/photo-editor). Пока Atlas не догонит их, они остаются рабочими.

Личный некоммерческий проект. Всё работает в браузере: фото не покидают компьютер, нет рекламы и сбора данных. Код написан ИИ-помощником Claude.

## Запуск

- В браузере: https://gregory-gittools.github.io/atlas/
- С компьютера: `start.bat` (нужен Python) — откроет `http://localhost:8644/`.

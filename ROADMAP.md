## 0. Данные и доступ (решено 2026-10-27)

- **Сначала на устройстве.** Своего сервера с данными нет. Личное (настройки, избранное, кэши, поездки) хранится в браузере этого устройства — так работает по умолчанию; правило для разработки: ни один модуль не отправляет личное наружу без явного действия.
- **Регистрация не обязательна.** Без входа — полноценная работа. Вход через Google — только чтобы синхронизировать личное между устройствами.
- **Облако — Google Drive**, скрытая папка приложения (видит только Atlas, файлы на диске пользователя). Без своего сервера: браузер работает с Drive напрямую. Нужен бесплатный проект Google Cloud (OAuth client ID) — создать при подключении. Фотоархив в облако не синхронизируется — только «что есть и где».
- **GitHub** — только публичное: экскурсии, языки, опубликованные фото; писать может только владелец.
- **Уровни доступа:** гость (без входа) · со входом (синхронизация) · владелец (публикация). Соавторов и ссылок «поделиться» не будет (Грегори: «кому нужно — разберётся»).
- **Без входа между устройствами** — перенос настроек файлом или QR-кодом.
- **«Что уходит в сеть»** — экран в настройках: у каждого модуля видно, что он отправляет (район карты, текст запроса, звук), и переключатель; общий режим «без сети».
- **Своё, а не чужие CDN:** шрифты и библиотеки — в репозитории (приватность и офлайн).
- **Приоритет офлайн:** (1) всегда на устройстве — свои фото, правка, разговорники, перевод, голос Piper; (2) пакет «поездка» — карта района (PMTiles), фото остановок, голос, языковая пара; (3) только в сети — поиск мест, распознавание речи, живые слои. Хранилище — «постоянное» (`navigator.storage.persist()`), чтобы браузер не стёр скачанное.

## 3. Перевод

Грегори пользуется всеми четырьмя вариантами в разных приложениях — собрать в одном. Сначала присмотреть готовые решения, потом подключать модулями.

- [ ] **Разговор вживую**: говорю по-русски — телефон произносит на языке страны, и наоборот
- [ ] **Камера**: вывески и меню — навёл и прочитал перевод
- [ ] **Текст в программе**: описания мест, Википедия, подписи к фото
- [ ] **Свой ввод в разговорнике**: набрал фразу — перевод, озвучка голосом страны, сохранить в разговорник

Кандидаты (проверить перед выбором):
- перевод на устройстве — Chrome Translator API и Language Detector (без ключа, работает офлайн после загрузки языка); запасной — Bergamot (движок переводов Firefox, WebAssembly)
- распознавание речи — Web Speech API (Chrome; на телефоне работает, нужен интернет)
- текст с камеры — Tesseract.js или встроенный ИИ Chrome (Prompt API с картинкой)
- голос страны — голоса браузера или Piper (см. ниже)

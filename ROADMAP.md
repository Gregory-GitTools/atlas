## 1. Ядро (без него модули не работают)

- [x] Реестр модулей: гнёзда `layers/`, `sources/`, `tools/`, `voices/`, загрузка тяжёлого по надобности
- [x] Общий стиль: все цвета, шрифт, размеры — переменные в одном месте
- [ ] **Окна-панели** — один компонент на всё: открыть, свернуть, закрыть, растянуть; на телефоне — своя раскладка; одновременно открыта одна панель
- [ ] **Связь модулей** — общие события: выбрано место, открыт снимок, текущая остановка, язык страны. Модули слушают события, а не знают друг друга
- [ ] **Настройки** — одно хранилище на устройстве; выгрузка и загрузка файлом (перенос между двумя компьютерами)
- [ ] **Хранилище** — кэши (места, EXIF, миниатюры) и **менеджер моделей**: голоса, переводчик, ИИ-модели качаются один раз, видно размер, можно удалить
- [ ] **Доступ к папкам** — запомнить папку, переспросить разрешение, автообновление при изменении файлов (File System Observer)
- [ ] **Данные экскурсий и языков** — из репозитория travel-earth и из своей папки
- [ ] **Источники и лицензии** — каждый модуль сам сообщает, что показывать в строке источников ⓘ
- [ ] **Обновление версии** — телефон не держит старый код (опыт travel-earth)
- [ ] **Установка** — одна кнопка, Edge ради голосов (опыт travel-earth), инструкция для людей
- [ ] **Локальный сервер** — один на всё: файлы, список папки, «открыть файл», «открыть папку в Проводнике», ярлыки
- [ ] **Проверка** — тестовый скрипт в репозитории: открыть приложение, включить каждый модуль, снять экран, собрать ошибки

## 3. Перевод

Грегори пользуется всеми четырьмя вариантами в разных приложениях — собрать в одном. Сначала присмотреть готовые решения, потом подключать модулями.

- [ ] **Разговор вживую**: говорю по-русски — телефон произносит на языке страны, и наоборот
- [ ] **Камера**: вывески и меню — навёл и прочитал перевод
- [ ] **Текст в программе**: описания мест, Википедия, подписи к фото
- [ ] **Свой ввод в разговорнике**: набрал фразу — перевод, озвучка голосом страны, сохранить в разговорник

Кандидаты (проверить перед выбором):
- перевод на устройстве — Chrome Translator API и Language Detector (без ключа, работает офлайн после загрузки языка); запасной — Bergamot (движок переводов Firefox, WebAssembly)
- распознавание речи — Web Speech API (Chrome; на телефоне работает, нужен интернет)
- текст с камеры — Tesseract.js или встроенный ИИ Chrome (Prompt API с картинкой)
- голос страны — голоса браузера или Piper (см. ниже)

## 4. Голос

- [ ] Голоса браузера (как в travel-earth) — модулем
- [ ] **Piper в браузере** — хороший голос на любом устройстве, офлайн; русские голоса irina, denis, dmitri, ruslan — сначала проба качества

- [ ] Источники: Commons (с поиском по «что на снимке»), Mapillary, Panoramax, свои фото

- [ ] Инструменты photo-editor: горизонт, поворот, перспектива, кадрирование, цвет, шумоподавление, EXIF
- [ ] HEIC с iPhone
